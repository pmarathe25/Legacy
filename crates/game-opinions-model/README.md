# Personal assessment data

Serializable individual trust, fear, obligation, and sensitivity records shared with the opinions owner, plus parallel merging of directed feeling updates. Values are assessments held by people rather than universal social rules.

`affinity_work_success`, `affinity_work_refusal`, and `affinity_work_failure` are independent optional signed reactions. A relationship case can override them for a particular other person with `work_success`, `work_refusal`, and `work_failure`. Omitted reactions default to no change; witnessing rules belong to the feature that produces the experience.
