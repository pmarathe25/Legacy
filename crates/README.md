# Crates

The workspace contains the simulation and its typed feature owners. [game-economy](game-economy/README.md) composes physical state, personal decisions and feature owners into staged, validated simulation boundaries. [game-economy-player](game-economy-player/README.md) exposes the player-facing view, and [game-economy-cli](game-economy-cli/README.md) provides the text interface.

Individual crate READMEs describe their responsibilities and behavioral boundaries. Content definitions live in the repository's `content/` directory.

[game-mechanics](game-mechanics/README.md) provides parallel apparatus experiments. The interval host supports personal design, experiments, watching, and real load movement with carried identified parts; broader discovery remains unfinished.

[game-personal-conflict](game-personal-conflict/README.md) stages simultaneous individually chosen strikes and target-grouped harm. The interval host owns health consequences and personal choices.

[game-signals](game-signals/README.md) owns voluntary nonverbal expressions and each observer's own interpretations, reactions and optional memories. Broader signal-driven care and learned interpretations remain unfinished.

[game-work-capability](game-work-capability/README.md) evaluates data-defined physical capability for chosen production work. It does not make work decisions or determine carrying capacity.
