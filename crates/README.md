# Crates

The `crates/` directory contains 131 small crates—each owning one simulation mechanic, storage structure, or application adapter.

**Why it matters:** Strict single-owner boundaries keep dependencies acyclic, let feature tests compose their required plugins without importing `game-assembly`, and prevent cross-module state corruption.

Recent extensions have separate owners:

| Crate | Responsibility |
| --- | --- |
| [game-identity](game-identity/README.md) | Acquired commitments and genetically influenced switching costs |
| [game-phonology](game-phonology/README.md) | Numeric phonemes and reversible IAST-based display |
| [game-grammar](game-grammar/README.md) | Pure construction learning, role particles, and embedded clauses |
| [game-syntax](game-syntax/README.md) | Grounded relational speech and personal learning in actual encounters |
| [game-attraction](game-attraction/README.md) | Subjective tastes and perceived compatibility |
| [game-violence](game-violence/README.md) | Dispositions and acquired moral responses to violence |
| [game-memory](game-memory/README.md) | Single personal memory store, sleep consolidation, fading, hereditary potential and reconstructive recall |
| [game-recollection](game-recollection/README.md) | Experienced episode recording and personal creative inspiration |
| [game-inscription](game-inscription/README.md) | Physical surfaces and compatible mark-making methods |
| [game-orthography](game-orthography/README.md) | Pure finite symbol encoding |
| [game-simple-machines](game-simple-machines/README.md) | Elementary geometry and work-port compatibility |

## Key rules

- **One owner per resource:** Only the plugin that declares a resource may mutate it.
- **Acyclic dependencies:** Lower crates emit events/notifications; upper crates subscribe and send typed requests downward.
- **Enforced budgets:** [Architecture tests](game-assembly/tests/architecture.rs) verify dependency direction and source-size limits (typically ≤600 lines in `src/`). See [`docs/design/feature-ownership.md`](../docs/design/feature-ownership.md) for boundary rationales.
- **Isolated verification:** Check or test any crate directly:
  ```sh
  cargo check -p game-agriculture --lib
  cargo test -p game-agriculture
  ```
