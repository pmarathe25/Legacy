# game-violence

Combines learned moral attitudes with inherited dispositions to violence.
`ethics` weighs personal values for violence, peace, and care. Escalation and
retaliation owners combine this with aggression, ambition, patience, relationships,
physical need, and expected consequences. No trait mandates an attack.

Experienced strikes can change participants' values. Empathy and compassion can
encourage aversion, while aggression can encourage the opposite response; rigidity
can resist this learning. Actual discussion can spread acquired values through
`game-discourse`. Gene distributions therefore do not determine a society's norms.
Pressure tests verify that peaceful convictions can outweigh high aggression and
violent convictions can motivate a less aggressive individual.
