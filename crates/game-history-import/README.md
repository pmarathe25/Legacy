# game-history-import

Strict audit and narrow physical-subset adapter for the preserved settlement
prototype. Unknown resource owners, active commitments, inventory contents,
pending jobs, historical notices and command receipts are rejected with paths.
Mature Legacy histories therefore cannot be imported. Never replace an original
checkpoint with this adapter's result.

For the tiny supported subset, person IDs, area IDs and time are preserved.
Names/genomes are synthetic only when their corresponding original owners are
absent; health is scaled by 60 and the new prototype's physical rules apply.
This is not an adapter for the primary `game-parallel` engine.
