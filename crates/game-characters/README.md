# game-characters

Characters have dispositions, relationships, aspirations, and remembered information. They rank available choices using their own knowledge and experience. Companionship, family plans, instruction, practice, and learned values can shape later decisions.

The crate owns personal judgments, plans, retries, learning, and social development. Other features supply factual opportunities, expected benefits, effort, uncertainty, and risk; Characters chooses among them. Executable actions remain opaque to its decision systems.

`Mind<A>`, `Stocks`, and inherited temperament are plain components in the shared store. `Stocks` owns dated inventory observations; `Mind<A>` owns plans, relationships, routes, and other personal information. Small typed interfaces expose observations and prepared changes. `MemoryLearner` receives historical stock and route information while retaining newer observations, current access rights, and existing routes. Temperament interprets opaque inherited alleles and combines predispositions with bounded experience. Biological aging and reproduction belong to Lifecycle; physical command admission belongs to the respective action owner.

Prepared stock learning stages the selected native `Stocks` row in the shared batch. Its guard checks the recipient and batch identity while allowing independent changes to other actors. Historical route learning guards the affected edge and receiving mind, then finishes the admitted field change. Both preserve newer observations and current access rights. Characters also decides whether a recipient agrees to voluntary memory instruction.
