# Fused physical needs

Prepares physical needs and active work in the same person-owned block traversal.
The fused scarce-food arrival benchmark can be run with `cargo run --release -p game-parallel-fused-physical --example fused_combat_rounds -- 1 1000000 hot food 3`. It measures a full tick after interleaved arrivals; compare worker counts and use `spread` for dense identities. Import and export are outside the timed tick.
