# game-food-actions

Executes learned food intentions through ordinary travel, gathering, and eating requests. `acquire` obtains a source without consuming the actor's meal, allowing a care owner to deliver it to a beneficiary. Provisioning owns source comparison and experience; this crate owns the physical stages. Partial collection uses an explicit target and minimum acceptable harvest.

Pending plans retain the existing enum save format. Feature tests remain in `game-provisioning` and the dependent-care owner.
