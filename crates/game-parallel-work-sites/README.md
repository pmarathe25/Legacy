# Physical work sites
Owns physical sites, recipe capacity requirements, and job-to-site bindings. Provisional admissions use deterministic parallel capacity allocation; bindings publish only after actual physical work starts and persist through pauses. Sites are physical infrastructure, not social authorities. Sites can be authored or created by a separate personal construction owner using real kits. Idle sites can be destroyed without salvage; transport remains to be modeled.

When callers supply personal access choices, allocation first considers each worker's sole-claimed sites, then open sites for workers respecting assertions, then remaining capacity for workers choosing to disregard them. Competing assertions do not grant access to any respectful claimant. Site and input reservations are conservative: a selected worker who later fails an input reservation can leave capacity unused for that boundary; mixed slot sizes can also leave gaps.
