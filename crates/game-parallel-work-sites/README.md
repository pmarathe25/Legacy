# Physical work sites
Owns physical sites, recipe capacity requirements, and job-to-site bindings. Provisional admissions use deterministic parallel capacity allocation; bindings publish only after actual physical work starts and persist through pauses. Sites are physical infrastructure, not social authorities. Sites can be authored or created by a separate personal construction owner using real kits. Idle sites can be destroyed without salvage; transport remains to be modeled.

When callers supply personal access choices, allocation first considers each worker's sole-claimed sites, then open sites for workers respecting assertions, then remaining capacity for workers choosing to disregard them. Competing assertions do not grant access to any respectful claimant. Work planning can reconsider provisional site winners that fail input admission for up to four virtual rounds. Capacity can still go unused after that bound or when later physical actions conflict; mixed slot sizes can also leave gaps.

The composed economy's `concentrated_site_refill_benchmark` exercises input contention and repeated site admission. Set `LEGACY_PEOPLE` and `LEGACY_WORKERS`, then run `cargo test --release -p game-parallel-economy concentrated_site_refill_benchmark -- --ignored --nocapture` to measure a complete boundary. The test also checks that most site capacity is used; compare worker counts on an otherwise idle machine.
