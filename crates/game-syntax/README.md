# game-syntax

Relational speech in actual social encounters composes `game-communication` words
and `game-grammar` constructions. Characters start without syntax. Contact, personal
observations, and demonstrations support learning; advanced cognition permits
further experimentation after simpler conventions are established.

Characters discuss visible people, places, and demonstrated carried goods. Actual
feeding records personally witnessed scenes. Mere proximity grants no vocabulary
or grammar. `Describe` validates contact and the speaker's observations; `Read`
returns only the reader's own remembered or currently interpretable meanings.
Two speakers can disagree on word order and particles. No generation counter copies
rules or unlocks a universal language. Children must learn through actual contact.

`Languages` owns up to 16 observed scenes and eight heard utterances per person.
The `syntax.learned` event records newly productive personal constructions. This
feature supplies conversational grammar; literary works retain their existing
composition format rather than being silently rewritten as fluent prose.

Other observation owners can submit `Witness` for personally perceived relational
content. The originating feature validates the perception; syntax validates the
observer's capability and the bounded frame. This grants no bystander knowledge,
word meaning, or construction. New event types can therefore use the same grammar
mechanisms without moving their physics or perception logic into the language owner.
Learning a demonstrated particle or embedded construction requires less inference
than inventing one, while very limited individuals can still fail to learn it.

Newly productive-construction milestones include the heard phonemes and the learner's
understood scene. Compact history can therefore retain dated examples of language
change without logging every conversation. Previously understood utterances preserve
the listener's remembered contextual interpretation rather than silently adopting a
later dictionary reading.
