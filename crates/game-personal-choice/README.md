# Personal choice

Feature owners may supply typed opportunities and subjective values from a
person's accessible evidence. This owner compares them with that person's own
domain inclinations, personal tie behavior and an explicit idle alternative. Disabled and unlisted
domains cannot win, and selection is an intention, not a physical commitment
or a decision by another person. Scoring uses checked-width integer arithmetic,
stable semantic tie-breaking, and parallel per-person batches.
Optional sorted `actions` refine a person's domain preferences using a signed
bias or an explicit refusal for an individual domain and action key. They can
therefore like or dislike different foods, recipes, or experiments separately;
an action refinement does not activate an unlisted or disabled domain.
The owner considers all supplied domains and opportunities rather than
rejecting or silently truncating a person's choices at an arbitrary count.

An optional authored birth profile can initialize general domain inclinations
for actual newborns using their own expressed genes. It copies no other
person's target-specific preferences, memories or decisions. The profile does
not create physical opportunities or bypass other owners' existing eligibility
rules; genetic effects and refusal are configured rather than universal.
For a newborn enrolled with a meal-domain profile, the interval host enables
meal consideration even without a configured dependent-care owner. The
individual profile still decides whether a meal wins over idleness.
When the profile explicitly includes work, its enabled setting initializes
the newborn's work-readiness flag rather than copying the mother's flag; the
newborn's own choice still decides whether to pursue a work opportunity.

The interval host can opt in to using this selection for construction,
local carrying, site maintenance, work starts, mechanical experiments,
meals, tool repair, local food pickup and self-treatment. This is not yet a
common chooser for other activities; their existing fixed-order scheduling
remains in effect.

Separately, an opted-in person can compare continuing an ordinary active job
with stopping; shared sessions and direct switches remain outside this slice.
