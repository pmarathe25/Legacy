# game-worldgen

Generates deterministic physical initial conditions from a seed and [runtime settings](../../content/worldgen/default.toml). Its output is a validated `game-scenarios::Definition`, without authored institutions, offices, bonds, buildings, farms, or settlements. A seeded spanning tree links natural areas; biomes supply local climate, wild food, and independent renewable materials or finite deposits. Each biome adds several resource populations with its own stock, replenishment, and optional climate gates. Each person receives independently generated traits sampled from every authored catalog range, beliefs, a name, a carried supply, and an individual possession claim.

This crate is a pure content generator. It does not invent historical records, run a second simulation, mutate another feature, or define character behavior. `game-openings` installs its result through ordinary owners, runs the authoritative host for the requested history duration, then begins player control. The default settings create 96 mortals and two guardians across 12 areas and run two simulated days. Population, area count, duration, biome choices, and name fragments are data. The supported population limit includes guardians.

Biomes can set `food_stock_per_person` and `food_renew_per_person`; omitted values retain 600 and 400. Renewal cannot exceed stock capacity. These describe physical resource abundance, independently of any society or character behavior. Material and additional deposits have their own replenishment settings.

History uses ordinary survival, work, cultivation, care, pastimes, companionship, households, births, exchange, membership changes, and coercive conflict. There is no geological generator or animal ecology. Family preferences and institutional choices remain limited templates, described in the deferred autonomy plan. Increasing history duration does not synthesize missing systems. Existing physical scarcity and mortality continue normally.

Run `cargo test -p game-worldgen`. Tests check deterministic seeds, varied physical starts, references and bounds, and the absence of preconstructed societies. Dependencies are `game-core`, `game-content`, `game-scenarios`, `game-physiology`, `game-relationships`, `game-traits`, and `serde`.
