# game-lineage

`game-lineage` tracks the current incarnation, succession waiting state, and guardians’ targets and goals. After a death, it binds the lineage to an actual, living newborn created later with zero initial age and two parents; simultaneous eligible births resolve by person ID. Guardians sense the newborn’s location, while reaching them still requires physical travel.

Guardians build readiness from conduct they witness and assess evidence according to their own traits. Readiness allows requests to be considered; body constraints, pending duties, visible distress, and individual judgment can still block them. Remembered thirst can motivate a real water trip until renewed contact resolves it. The crate returns lineage state and guardian intentions for the world adapter to apply.
