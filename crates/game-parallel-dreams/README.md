# Personal aspirations

An authored, enduring craft aspiration periodically creates or renews a concrete personal work goal. A completed goal can be renewed for another configured batch; unfinished or explicitly disabled goals are not overwritten. Each person must be alive at the review boundary. Actual input reservations and completed production remain with their respective owners.
Players can inspect aspirations with `dreams PERSON` and change one with `dream-set PERSON RECIPE PRIORITY BATCH INTERVAL enable|disable`. A disabled aspiration stops forming future goals; an existing goal remains a separate choice. The runnable fixture is `content/parallel/dreams.toml`.

Optional individual learning inclinations can form a bounded number of aspirations from successful work the person actually witnessed. Existing aspirations, including ones the person disabled, are never replaced. A new aspiration is reviewed at a later simulation boundary; it does not grant resources, skills, or an obligation to work.
