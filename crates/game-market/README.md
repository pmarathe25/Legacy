# market

Pending offers and explicit recipient acceptance, refusal, and proposer withdrawal. Offers do not reserve possessions; acceptance must recheck physical availability and capacity. This owner records decisions, while the goods-cargo owner performs any exchange.

An individual market policy can set signed `opinion_weights` for affinity,
trust, fear, and obligation. Setting an influence to zero lets the actor
disregard it when evaluating that offer. An omitted profile preserves existing
unit weights for fear and obligation. Attached offers remain revocable, and
settlement requires actual goods and holding capacity.
