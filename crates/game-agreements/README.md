# game-agreements

`game-agreements` lets people negotiate promises and choose how to amend them. Terms cover access, deliveries, labor, construction, and output shares. The domain decides acceptance, revisions, chosen quorums, and obligations from supplied contact and asset facts.

The ledger tracks work and defaults, credits each interval once, and preserves fractional output shares and previously performed duties when terms change. Prepared transitions reject stale records before committing. They return permission, obligation, and notice effects; the world applies these to actual people and resources.
