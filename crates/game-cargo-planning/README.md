# game-cargo-planning

Provisional, read-only allocation of physical cargo claims. The cargo owner
continues to own and validate all mutations. A plan is not a reservation: callers
must revalidate permissions, location, eligibility, lots and effects. The
experimental selected-meal cohort uses the planner for self-meals; no current
action commits participant reservations. Additional participants can be named
to prevent conflicting joint proposals from both being admitted.
