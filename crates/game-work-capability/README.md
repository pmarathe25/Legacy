# Work capability

An optional data-defined physical feasibility model for production. A body's
age (in family simulation ticks) and genetic vigor determine strength through an authored growth curve;
recipe-specific requirements and an explicit default decide whether a start
is physically possible. Missing bodies have an explicit fallback or are
denied. This does not choose work, impose obligations, consume resources, or
model carrying capacity. A host must check the same rule before admission.
The current interval-host integration applies only to personally chosen
production starts. Existing active work is not invalidated when capability
later changes; newborns need no separate capability record. Other activities
remain separate work. Optional newborn choice profiles are configured by the
personal-choice owner, independently of physical capability.
