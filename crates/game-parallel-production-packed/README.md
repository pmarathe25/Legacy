# Packed production experiment

Stores persistent jobs in fixed-size blocks with compact rows and block-local interned exact input/output bundles. Tick preparation reads a shared physical snapshot, reduces abundant output directly, and resolves contested output through deterministic per-stock block prefixes. Publication updates each block independently and retains exact waiting-job quantities. The compiled host uses it for manual and autonomous work, including market-enabled worlds. Explicit market commands and some job edits currently materialize the ordinary jobs. Interleaved job IDs and certain edit commands temporarily materialize jobs.
