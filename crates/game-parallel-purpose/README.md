# Purpose need

Optional individual purpose deprivation is data-defined. Time and failed goal attempts increase deprivation; real goal progress relieves it. At the configured threshold, health damage applies to living people. These rules are separate from hunger, fatigue, and social isolation.
Newborns enrolled by the family owner start this need at biological adulthood; an authored `eligible_at` can set a different first active tick. `content/parallel/purpose.toml` supplies a runnable example.
The owner requires work goals in this first implementation, so that its recovery and setback signals come from actual actions and resource arbitration.
