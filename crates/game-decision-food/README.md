# game-decision-food

Opt-in preparation of food opportunities across a decision-frame cohort. Registers
an auxiliary provider and a private input payload under the character owner. It
adds no resource or plugin manifest entry. The auxiliary query shares the existing
actor/provider pool submission and never enters ordinary choice arbitration.

With frame food preparation enabled, characters use their cohort snapshot's food
alternatives. Motive scoring, urgency and physical execution remain live. This is
an additional snapshot-model option, not an exact cache of later live queries.
Missing or rejected preparation falls back to ordinary provisioning. Typed payloads
also decode after a midframe save/load. Disabled policies use the original query.
