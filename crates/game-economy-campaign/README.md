# Ruler lineage over the economic world

Stages the ruler's actual succession, invocation costs, and guardian journeys alongside personal life, travel, and physical custody. Warnings require an explicit game choice before a cost applies.

The interval campaign uses absolute times for deaths, subsequent births, and
invocation costs. A warning pauses advancement at the due instant until the
player accepts or dismisses it. An accepted cost can change health, shorten the
current lifespan, or suspend control. A successor has their own possessions
and relationships. Corporeal guardians use ordinary journeys and make their
own mentorship judgments.

Start a headless session with `cargo run -p game-economy-cli -- --interval-campaign SCENARIO`.
Use `campaign` to inspect the lineage, `invoke PAST_LIVES` to invoke recorded
lives, and `accept-cost REVISION` or `dismiss` to respond to a warning.
`recall-life LIFE` shows the invoked predecessor's retained observations,
techniques, and language without transferring them into the current person's
memory. Practiced capability projection and abstract guardians still need
interval integration.
