# game-campaign

The generated-world autonomy preset composes typed feature requests. `Start` registers founder genotypes and enables provisioning reserves, voluntary families, exchange, works, preservation, equipment, travel, horticulture, care, livelihoods, pastimes, and communities. It adds no alternate simulation loop.

Generated starts use an explicit calendar epoch and varied adult ages. Campaign needs and decisions use an authored half-day cadence. Fixture profiles retain their minute-scale tuning. The feature tests compose lower owners directly without game-assembly.
