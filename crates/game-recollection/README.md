# game-recollection

Retains up to 32 sampled personal episodes per person. Actual participants can
remember feeding, birth, or combat; deaths are remembered only by local observers.
Cognitive ability can prevent retention. Episodes are delivered through the
knowledge owner's requests and, when available, grounded syntax observations.
No world chronicle is granted to characters.

`inspiration` selects a bounded sample of personally retained episodes, theories,
measurements, and environmental knowledge. Personal events take precedence over
routine patch facts; deterministic personal selection avoids every creator using
the same first-sorted patches. Unchanged evidence does not cause daily random
recompositions. `game-works` owns compositions and their circulation.

Literary tests cover care as a subject, physical composition, reader-relative
understanding, and replay. These remain short procedural compositions, rather
than fluent generated human prose.
