# game-recollection

Bridges experienced feeding, births, actual combat hits and locally observed deaths
into the single `game-memory` personal evidence store through knowledge requests.
The old separate 32-slot episode sample no longer exists. Repeated episodes of a
particular relation/actor/patient update that personal theme; memory retention,
consolidation, crowding, fading and recall belong to `game-memory`. Relationships
and experienced emotional context can make an episode significant; no global
chronicle or other character's private thoughts are granted.

`inspiration` is a read-only, bounded selection of personally retained episodes,
theories, measurements and environmental knowledge. Personal events take precedence
over routine patches. Actual creative use in `game-works` recalls the selected
memories; merely proposing possible activities never rehearses them. Physical
compositions and circulation remain owned by `game-works`.
