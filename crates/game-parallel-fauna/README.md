# Individual wildlife

This owner stages individual animals with data-defined species, diploid inherited traits, hunger, health, aging and gestation. Animals graze finite, local patches supplied by the physical resource owner; deterministic parallel allocation prevents competing animals from consuming the same food. Births use actual local parents and deterministic IDs. The host must validate the committed population and atomically publish both the returned animal generation and patch consumption.

The economic host runs wildlife after successfully staged human gathering and patch renewal, then deducts actual grazing from the same remaining patches before the tick commits. A controlled person can offer a local animal real carried food. Only consumed food matching its diet affects its hunger and subsequent grazing; the action reports food used, not its nutritional effect. `content/parallel/economy-wildlife.toml` supplies a playable example using named food content. Autonomous human feeding, handling, capture and climate effects are not yet implemented here.
