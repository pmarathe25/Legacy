# Economic scenario runner

Run `cargo run -p game-parallel-economy-cli`, optionally passing a scenario TOML path. The default scenario loads goods and recipes from `content/objects` and `content/workshop`. `help` lists commands; `work`, `social`, `yield` and `treat` change an individual's future choices and `go` starts a journey along an authored route. `expedition`, `invite-expedition`, `meet-expedition` and `cancel-expedition` operate personal journeys and goals. `claims`, `claim`, `unclaim`, `take-claimed` and `claim-output` expose individual assertions and preferences. `health` displays current infections and meetings. `promise`, `decide`, and `honor` expose personal promises and choices; `catalog` lists good IDs. Scenarios can supply family, dependent-care, agreement, route, personal dynamics and named aspiration data. Save files contain exact physical lots, deadlines, journeys and disease state, and are validated before loading.

This runner currently exposes the composed economic slice, not the complete campaign simulation.

For a ruler and guardians in the same dated-goods world, run `cargo run -p game-parallel-economy-cli -- content/parallel/economy-campaign.toml`. `ruler` shows the current incarnation, guardians and any pending invocation warning. `invoke`, `dismiss-invocation`, `accept-warning`, and `guardian-release` operate those personal abilities and choices. A pending warning leaves the simulation time unchanged until it is accepted or invocation is dismissed.

`start-work PERSON RECIPE UNITS` and `continue-work PERSON` let a controlled person spend time starting and working on a real job; `catalog` lists recipe IDs. `meet PERSON TARGET` attempts an actual encounter. `knowledge PERSON` displays that person's bounded food observations and reports, and `past-knowledge LIFE` requires that life to be actively invoked. The default runner is an administrative interface and can inspect other individuals.

Run `cargo run -p game-parallel-economy-cli -- --player` for a ruler-bound view of the authored campaign. `view` shows the current person's local surroundings, resources, possessions, job, health, fatigue, isolation, purpose, seasonal conditions, personal food reports and current fight. `catalog` lists data-defined goods and production recipes. `eat`, `treat`, `treat-other`, `farm`, `gather`, `give`, `take`, `store`, and `recover` use physical local resources, carried goods, and stocks; travelers can eat carried food while their journey advances. `rest` advances time and recovers fatigue. A player can request food or work, make or fulfill personal promises, or initiate and direct a tactical fight; other individuals choose their own responses. `step` advances a shared round along with the rest of the world. `guardians` is the explicit search-spectating view. Player mode is still an incomplete game interface.
